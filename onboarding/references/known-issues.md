# Known issues register — tools & disrupt-sc

Protocol (RUNBOOK.md standing rule 2): when a phase hits one of these, apply the recorded
resolution if one exists; when a NEW issue surfaces, ask the user (fix tool / use as-is /
defer) and append it here with a new KI id + the decision.

Status: `open` = no decision yet · `workaround` = agreed workaround, tool unchanged ·
`fixed` = patched locally · `wontfix` = accepted behavior.
